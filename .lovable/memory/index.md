# Project Memory

## Core
This project is ecrenta.space — a Fresno County rental marketplace. NOT runp8. Never call it runp8 or confuse the two.
ecrenta = tenant listings browse + landlord messenger inbox. Green #16A34A primary, warm cream bg. Space Grotesk headings, DM Sans body.
Business model is flat landlord subscriptions + free tenants. NO commissions on rentals (explicit decision, do not propose commission models).
runp8.com is a SEPARATE product: P8 AI property management SaaS (VA / Inspector / Growth modes). Don't mix vision, branding, or monetization between the two.
